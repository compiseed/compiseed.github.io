# CompiSeed アプリ公式サイト

GitHub Pagesで配信する、依存ライブラリー・ビルド工程のない静的サイトです。

| URL | 内容 |
|---|---|
| `/` | 2アプリの一覧と共通のGitHubお問い合わせ先 |
| `/nail-study/` | Nail Study - ネイル検定対策の紹介 |
| `/privacy.html` | Nail Studyの既存プライバシーポリシー。URLと本文を維持 |
| `/wooden-puzzle/` | 木のおもちゃパズル幼児向けの紹介。公開準備中 |
| `/wooden-puzzle/privacy.html` | パズルの現行v0.12.1向けプライバシーポリシー |

## 更新

ロゴは利用者選択のC案を採用：マークのみ70％に縮小し、各画面幅の既存の社名文字サイズを維持。assets/brand.jsで文字の実描画下端と、元画像のひし形の先端を合わせています。共通ヘッダーのある4ページで共有します。

2026年10月22日、利用者提供のCompiSeedロゴをヘッダーに追加。Nail Studyの紹介文は日本語のGoogle Play掲載内容を確認して要約し、公式アイコン、掲載スクリーンショット3枚、ストアリンクを追加しています。出典：https://play.google.com/store/apps/details?id=jp.compiseed.nailstudy&hl=ja&gl=JP 。掲載内容が変わった場合は分野数・問題数・機能を再確認してください。ロゴの原画像はassets/compiseed-logo.jpgとして保持し、ヘッダーではCSSでシンボル部分を表示しています。

HTMLと`assets/site.css`を編集します。画像は既存の生成アイコンと実アプリのスクリーンショットの表示用縮小コピーです。外部のJavaScript・Webフォント・独自アクセス解析・問い合わせフォームは追加していません。

新しいアプリを増やす場合はアプリ用のフォルダーとポリシーを追加し、トップページへ紹介カードを足してください。既にストアなどから参照されるポリシーURLは維持します。同じパブリッシャーIDを使用する場合、app-ads.txtへアプリごとの行を重複追加する必要はありません。

## 次の公開準備で更新する内容

- パズルへ広告SDKを組み込む前に、実際に利用するSDK・送信情報・子ども向け設定に合わせ、パズルのプライバシーポリシーを改定する。現在の本文は広告未導入版の実装を反映している。
- ストア公開後に、パズルの「公開準備中」を配信情報と実際のストアリンクへ変更する。
- お問い合わせ先は利用者指定により既存のGitHubプロフィールを継続。メールアドレスや問い合わせフォームを追加する場合は、利用者が公開先を指定してから変更する。

## ローカル確認

任意の静的HTTPサーバーでこのフォルダーを配信してください。例：`python -m http.server 8098 --bind 127.0.0.1`。トップ、各紹介ページ、両方のポリシー、app-ads.txtを確認します。
